Orbiterm

Terminal et client d’accès distant tout-en-un — version @VERSION@ · code source · téléchargements

Windows (winget)

winget install Kaguyu-M.Orbiterm

Windows (Scoop)

scoop bucket add orbiterm https://github.com/Kaguyu-M/orbiterm
scoop install orbiterm/orbiterm

Debian / Ubuntu

sudo curl -fsSLo /usr/share/keyrings/orbiterm.asc https://kaguyu-m.github.io/orbiterm/orbiterm.asc
sudo curl -fsSLo /etc/apt/sources.list.d/orbiterm.sources https://kaguyu-m.github.io/orbiterm/orbiterm.sources
sudo apt update && sudo apt install orbiterm

Fedora

sudo curl -fsSLo /etc/yum.repos.d/orbiterm.repo https://kaguyu-m.github.io/orbiterm/orbiterm.repo
sudo dnf install Orbiterm

NixOS / Nix

nix profile install github:Kaguyu-M/orbiterm

Les mises à jour arrivent ensuite par winget upgrade, scoop update, apt upgrade, dnf upgrade ou nix profile upgrade.
